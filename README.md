##  Descripción General

El propósito de este repositorio es documentar el aprendizaje, servir como bitácora de desarrollo y ofrecer una referencia práctica para la asignatura de **Programación Web**. 

A lo largo de las distintas carpetas se organizan:
1. **Ejemplos del Libro**: Recreación y prueba de los fragmentos de código presentados por los autores en cada capítulo.
2. **Ejercicios Propuestos Resueltos**: Solución a las actividades de autoevaluación, ejercicios de repaso y problemas prácticos
al final de cada capítulo (Capítulos 2 al 9).

El resultado aplicado del repositorio lo puedes visualizar en : 
![Pagina Web](https://not-abad.github.io/Programaci-n-Web/index.html)

## Instalación y Configuración

  <h3>Prerrequisitos</h3>
  <ul>
    <li>Un navegador web moderno (Google Chrome, Mozilla Firefox, Brave, Microsoft Edge).</li>
    <li><strong>Git</strong> instalado en tu sistema local.</li>
    <li>Un editor de código recomendado como <strong>Visual Studio Code</strong>.</li>
  </ul>

  <h3>Pasos de Clonación</h3>
  <ol>
    <li>Abre tu terminal de comandos o <strong>Git Bash</strong>.</li>
    <li>Clona este repositorio ejecutando:
      <pre><code>git clone https://github.com/Not-Abad/Programaci-n-Web.git</code></pre>
    </li>
    <li>Accede a la carpeta raíz del proyecto:
      <pre><code>cd Programaci-n-Web</code></pre>
    </li>
  </ol>

<hr>

## Instrucciones de Uso

  <ol>
    <li><strong>Navegación por Carpetas:</strong> Dirígete a la carpeta del capítulo que desees examinar (por ejemplo <code>capitulo-06-js-introduccion/ejercicios/</code>).</li>
    <li><strong>Visualización en Navegador:</strong>
      <ul>
        <li>Abre directamente cualquier archivo <code>.html</code> haciendo doble clic en él.</li>
        <li>Si utilizas <strong>Visual Studio Code</strong>, haz clic derecho sobre el archivo <code>.html</code> y selecciona <strong>Open with Live Server</strong> para habilitar la recarga automática.</li>
      </ul>
    </li>
    <li><strong>Inspección de Scripts:</strong>
      <ul>
        <li>Para evaluar el comportamiento en JavaScript, abre las <strong>Herramientas de Desarrollador</strong> de tu navegador (<code>F12</code> o <code>Ctrl + Shift + I</code>) y consulta la <strong>Consola</strong>.</li>
      </ul>
    </li>
  </ol>
