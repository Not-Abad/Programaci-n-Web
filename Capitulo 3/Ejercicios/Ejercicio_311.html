3.2.1 Tipo input color

El tipo input color permite al usuario introducir un color.

Opera muestra un control selector de color que despliega el color predeterminado (negro) con una flecha hacia abajo que muestra una lista desplegable con 20 colores básicos.

Los nuevos tipos de entrada de HTML5 cuentan con validación automática del lado del cliente, con lo cual se evita el envío de datos inválidos.

Haga clic a continuación para desplegar la tabla de tipos input y sus formatos:

Fig. 3.5 Tipos input con validación automática en HTML5
Tipo input Descripción Formato / Ejemplo válido
color Permite introducir un color mediante un código hexadecimal de 6 dígitos. #ff0000
date Introduce fecha (año, mes y día). 2026-09-14 (aaaa-mm-dd)
datetime-local Introduce fecha y hora local (sin zona horaria). 2026-09-14T17:30
email Dirección de correo con sintaxis estándar. usuario@dominio.com
month Introduce año y mes. 2026-09
number Introduce un valor numérico con límites opcionales. 25 (usa min, max, step)
range Control deslizante entre un mínimo y máximo. Rango entre min="1" y max="100"
search Campo de consulta de texto para búsqueda. Cualquier texto de búsqueda
tel Número de teléfono (validable con pattern). (555) 555-5555
time Hora (horas y minutos en formato 24h). 15:30 (hh:mm)
url Dirección web que incluye protocolo. http://www.deitel.com
week Año y número de semana. 2026-W37
