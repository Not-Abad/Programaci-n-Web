3.2 Indica si cada uno de los siguientes enunciados es verdadero o falso:


a) Cualquier tipo input particular de formulario de HTML5 debe desplegarse de manera idéntica en todos los navegadores compatibles con HTML5. R= False. El despliegue de los tipos input puede variar de un navegador a otro.

b) Cuando se coloca el enfoque en el campo de texto (es decir, si el cursor está en el campo de texto), se envía el texto del atributo placeholder al servidor. R= Falso. Cuando se coloca el enfoque en el campo de texto, el texto de placeholder desaparece. No se "envía" cuando el usuario hace clic en el botón

c) No es necesario incluir el atributo autofocus en sus formularios. R= Verdadero.

d) Los nuevos tipos input de HTML5 tienen validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos (scirpt) complicadas a sus formularios para validar la entrada del usuario y se reduce la cantidad de datos inválidos que se envían. R= Verdadero.

e) El tipo input range se valida automáticamente de manera intrínseca cuando el navegador lo despliega como un control deslizante, ya que el ususario no puede mover el control fuera de los límites del valor mínimos o máximos. R= Verdadero.

f) HTML5 cuenta con validaciín automática para el tipo input tel. R= Falso. La longitud y el formato de los números télefonicos varía de manera considerable con base en la ubicación, por lo que la validación se vuelve bastante compleja, así que HTML5 no cuenta con validación automática para el tipo input tel. Para asegurar que el usuario introduzca el número en un formato apropiado, usamos el atributo pattern.

g) Si el usuario introduce un URL con un formato inapropiado en un tipo input url, no se validará. HTML5 no valida si el URL introducido existe en realiada. R= Verdadero.

h) El elemento nav muestra un menú desplegable de hipervínculos. R= Falso. El elemento nav agrupa vínculos de navegación.

i) El elemento header puede usarse sólo una vez en una página. R= Faslo. El elemento headre puede usarse varias veces en una página y a menudo incluye encabezados de HTML (h1 a h6).

j) Los elementos nva pueden anidarse en un elemento aside. R= Verdadero.

k)Podemos usar el elemento brk para evitar dividir palabras en lugares incorrecots. R= Falso. Puede usar el elemento wbr para evitar dividir las palabras en lugares incorrectos
