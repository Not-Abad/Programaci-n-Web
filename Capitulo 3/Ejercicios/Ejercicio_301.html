3.1 Complete las siguientes oraciones:


a) El tipo input color permite al usuario introducir un color. Al momento de escribir eset libro, la mayoría de los navegadores despliegan el tipo input color sobre un campo de texto en donde el usuario puede introducir un Código hexadecimal.

b) El atributo placeholder nos permite colorcar texto temporal en un campo de texto.

c) Si desea anular la validación, puede agregar el atributo fomnovalidate al tipo input submit.

d) El atributo required obliga al usuario a introducir un valor antes de enviar el formulario.

e) Por lo general se muestra el control giratorio (spinner) para el tipo input number e inclute sólo los números válidos

f) El tipo input time permite al usuario a introducir una hora, minuto, segundo y fracción de segundo.

g) El elemento "datalist" proporciona opciones de entrada para un elemento input text.

h) El elemento "article" describe contenido que está separado del contenido principal de la página y que posiblemente podría utilizarse o distribuirse en otra parte, como un artículo de noticias, mensajes de foro o entrada de blog.

i) El elemento "footer" describe el texto que por lo general aparece en la parte inferior del contenido o de un elemento section.

j) El elemento "wbr" (Word Brak Opportunity) indica el lugar apropieado para dividir una palabra cuando el texto se ajusta en varias lineas.
