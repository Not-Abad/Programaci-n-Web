3.2.1 Tipo input color

El tipo input color permite al usuario introducir un color.

Opera muestra un control selector de color que despliega el color predeterminado (negro) con una flecha hacia abajo que, al hacer clic en ella, revela una lista desplegable con 20 colores básicos. El usuario puede seleccionar un color o hacer clic en el botón Otro... para seleccionar de entre colores básicos adicionales o crear un color personalizado.

Al momento de escribir este texto, la mayoría de los navegadores despliegan el tipo input color como un campo de texto en el cual el usuario puede introducir un código hexadecimal de 6 caracteres.

Los nuevos tipos de entrada de HTML5 cuentan con validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos JavaScript complejas. Por ejemplo, si un usuario introduce un valor hexadecimal incorrecto en un navegador como Chrome, aparecerá un mensaje de advertencia indicando el error.
