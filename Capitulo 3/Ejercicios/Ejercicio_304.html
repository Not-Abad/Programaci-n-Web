3.4 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué:


a) Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color. R= Falso. Requieren que se introduzca un valor hexadecimal de 6 caracteres (por ejemplo, #ffffff), no el nombre del color en texto.

b) Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos. R= Falso. El navegador sólo valida que los datos introducidos cumplan con las restricciones o formatos especificados, pero no puede verificar si los datos reales son verídicos o correctos.

c) HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad. R= Falso. HTML5 sólo verifica que la cadena coincida sintácticamente con el formato de una dirección de correo electrónico válida, no si la cuenta existe en realidad.

d) Puede agregar required a cualquiera de los tipos input. R= Falso. No se puede aplicar a tipos donde la selección ya está implícita o no es editable, como hidden, range, color ni en botones de comando (submit, reset, button).

e) Puede habilitar autocomplete sólo para ciertos elementos input. R= Verdadero.

f) El elemento time nos permite identificar una fecha, hora o ambas. R= Verdadero.

g) El elemento caption proporciona una leyenda para la imagen en un elemento figure. R= Falso. El elemento figcaption proporciona la leyenda en figure; caption se emplea para tablas.

h) El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary. R= Falso. El elemento summary es la leyenda visible; al pulsar la flecha se revela el contenido del elemento details.

i) El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section. R= Verdadero.

j) El elemento highlight nos permite resaltar texto. R= Falso. El elemento de HTML5 utilizado para resaltar texto es mark (highlight no existe en HTML5).
