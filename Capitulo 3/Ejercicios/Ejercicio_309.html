3.2.1 Tipo input color

El tipo input color permite al usuario introducir un color. Opera muestra un control selector de color que despliega el color predeterminado (negro) con una flecha hacia abajo que, al hacer clic en ella, revela una lista desplegable con 20 colores básicos. El usuario puede seleccionar un color o hacer clic en el botón Otro... para seleccionar de entre colores básicos adicionales o crear un color personalizado. Al momento de escribir este texto, la mayoría de los navegadores despliegan el tipo input color como un campo de texto en el cual el usuario puede introducir un código hexadecimal de 6 caracteres.

Los nuevos tipos de entrada de HTML5 cuentan con validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos JavaScript complejas a sus páginas Web para validar la entrada del usuario. Esto reduce la cantidad de datos inválidos enviados al servidor y disminuye el tráfico de red entre cliente y servidor. Por ejemplo, si un usuario introduce un valor hexadecimal incorrecto en un navegador que despliega el elemento color como un campo de texto (como Chrome), se mostrará una llamada emergente señalando hacia el campo, indicando que el valor introducido no es válido.
