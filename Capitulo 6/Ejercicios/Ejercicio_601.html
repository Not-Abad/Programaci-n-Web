Ejercicio 6.1: Completar las oraciones

Completar las oraciones sobre conceptos básicos y sintaxis de JavaScript.

  1. // comienza un comentario de una sola línea.
  2. Toda instrucción de JavaScript debe terminar con un(a) Punto y coma (;).
  3. La instrucción if se utiliza para tomar decisiones.
  4. El objeto window muestra diálogos alert y prompt.
  5. Las palabras Clave están reservadas para uso de JavaScript.
  6. Los métodos write y writeln del objeto document escriben texto de HTML5 en un documento de HTML5.
