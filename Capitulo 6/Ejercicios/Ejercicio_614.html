Ejercicio 6.14: Orden de Evaluación de Operadores

Determinar el orden de evaluación y el valor resultante de x.

  1. a) x = 7 + 3 * 6 / 2 - 1;
    Orden de evaluación: 3*6=18, 18/2=9, 7+9=16, 16-1=15.
    Valor final de x = 15
  2. b) x = 2 % 2 + 2 * 2 - 2 / 2;
    Orden de evaluación: 2%2=0, 2*2=4, 2/2=1, 0+4=4, 4-1=3.
    Valor final de x = 3
  3. c) x = ( 3 * 9 * ( 3 + ( 9 * 3 / ( 3 ) ) ) );
    Orden de evaluación: (9*3/3)=9, (3+9)=12, (3*9*12)=324.
    Valor final de x = 324
