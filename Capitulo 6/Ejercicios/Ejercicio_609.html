Ejercicio 6.9: Verdadero o Falso

Indicar si cada enunciado es verdadero o falso. Justificar las respuestas falsas.

  1. a) Los operadores de JavaScript se evalúan de izquierda a derecha.
    Falso Depende de las reglas de asociatividad de cada operador; por ejemplo, la asignación (=) se evalúa de derecha a izquierda.
  2. b) Los siguientes son nombres de variables válidos: _guion_bajo_, m928134, t5, j7, sus_ventas$, el_total_de_su_$cuenta, a, b$, c, z, z2.
    Verdadero
  3. c) Una expresión aritmética válida de JavaScript sin paréntesis se evalúa de izquierda a derecha.
    Falso Las expresiones aritméticas se evalúan según la precedencia de operadores (*, /, % primero; +, - después).
  4. d) Los siguientes son nombres de variables inválidos: 3g, 87, 67h2, h22, 2h.
    Falso La variable h22 es válida porque comienza con una letra. Las variables 3g, 87, 67h2 y 2h son inválidas por iniciar con un dígito.
