Ejercicio 6.12: Identificar Modificación de Variables

Determinar qué instrucciones modifican valores de variables.

  1. a) p = i + j + k + 7;
    Modifica la variable p.
  2. b) window.alert( "variables cuyos valores se destruyen" );
    No modifica ninguna variable.
  3. c) window.alert( "a = 5" );
    No modifica ninguna variable.
  4. d) cadenaVal = window.prompt( "Escriba una cadena:" );
    Modifica la variable cadenaVal.

Conclusión: Las instrucciones a) y d) son las únicas que modifican variables.
