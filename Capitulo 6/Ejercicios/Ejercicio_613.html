Ejercicio 6.13: Evaluación de la Ecuación y = ax³ + 7

Determinar cuáles instrucciones representan correctamente la ecuación.

  1. a) y = a * x * x * x + 7;
    Correcta
  2. b) y = a * x * x * ( x + 7 );
    Incorrecta Equivale a ax³ + 7ax².
  3. c) y = ( a * x ) * x * ( x + 7 );
    Incorrecta Equivale a ax³ + 7ax².
  4. d) y = ( a * x ) * x * x + 7;
    Correcta
  5. e) y = a * ( x * x * x ) + 7;
    Correcta
  6. f) y = a * x * ( x * x + 7 );
    Incorrecta Equivale a ax³ + 7ax.
