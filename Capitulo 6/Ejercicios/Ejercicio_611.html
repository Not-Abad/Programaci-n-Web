Evaluación de expresiones con x = 2 y y = 3.

  1. a) window.alert( "x = " + x );
    Muestra: x = 2
  2. b) window.alert( "El valor de x + x es " + ( x + x ) );
    Muestra: El valor de x + x es 4
  3. c) window.alert( "x =" );
    Muestra: x =
  4. d) window.alert( ( x + y ) + " = " + ( y + x ) );
    Muestra: 5 = 5
