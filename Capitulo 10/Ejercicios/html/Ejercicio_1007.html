Ejercicio 10.7: Verdadero o falso

Análisis de reglas de declaración, reserva de memoria e iteración de arreglos.

a) Para hacer referencia a una ubicación o elemento específico en un arreglo, especificamos el nombre del arreglo y el valor del elemento.
FalsoSe especifica el nombre del arreglo y el índice (posición) del elemento dentro de corchetes, no su valor.
b) La declaración de una variable reserva espacio para un arreglo.
FalsoLa declaración (var a;) solo crea el identificador; el espacio para el arreglo se reserva al asignarle una lista inicializadora [] o una instancia new Array().
c) Para indicar que deben reservarse 100 ubicaciones para el arreglo entero p, el programador debe escribir la siguiente declaración: p[ 100 ];
FalsoLa expresión p[ 100 ] intenta acceder al elemento en el índice 100. La declaración correcta es var p = new Array( 100 );.
d) Un programa de JavaScript que inicializa los elementos de un arreglo de 15 elementos en cero debe contener cuando menos una instrucción for.
FalsoPuede inicializarse directamente mediante una lista inicializadora (var a = [0, 0, ..., 0];) o el método fill(0) sin necesidad de un ciclo for.
e) Un programa de JavaScript que calcula el total de los elementos de un arreglo bidimensional debe contener instrucciones for anidadas.
FalsoAunque las instrucciones for anidadas son la forma más común, también puede calcularse usando ciclos while, do...while o sumando cada elemento individualmente.
