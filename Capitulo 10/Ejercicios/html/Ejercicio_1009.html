Ejercicio 10.9: Manipulación del arreglo bidimensional t

Operaciones sobre una matriz de dos filas por tres columnas.

a) Escriba una instrucción para declarar y crear el arreglo t.
var t = [ [ 0, 0, 0 ], [ 0, 0, 0 ] ];
b) ¿Cuántas filas tiene t?   c) ¿Cuántas columnas tiene t?   d) ¿Cuántos elementos tiene t?

Tiene 2 filas, 3 columnas y 6 elementos en total.

e) Nombres de todos los elementos en la fila 1 de t.

t[1][0], t[1][1] y t[1][2]

f) Nombres de todos los elementos en la tercera columna de t.

t[0][2] y t[1][2]

g) Sola instrucción para establecer el elemento de t en la fila 1 y la columna 2 en cero.
t[ 1 ][ 2 ] = 0;
h) Serie de instrucciones individuales para inicializar cada elemento de t en cero.
t[ 0 ][ 0 ] = 0;
t[ 0 ][ 1 ] = 0;
t[ 0 ][ 2 ] = 0;
t[ 1 ][ 0 ] = 0;
t[ 1 ][ 1 ] = 0;
t[ 1 ][ 2 ] = 0;
i) Instrucción for anidada para inicializar cada elemento de t en cero.
for ( var fila = 0; fila < t.length; ++fila )
{
   for ( var col = 0; col < t[ fila ].length; ++col )
   {
      t[ fila ][ col ] = 0;
   }
}
j) Serie de instrucciones para determinar e imprimir el valor más pequeño en el arreglo t.
var menor = t[ 0 ][ 0 ];
for ( var fila = 0; fila < t.length; ++fila )
{
   for ( var col = 0; col < t[ fila ].length; ++col )
   {
      if ( t[ fila ][ col ] < menor )
         menor = t[ fila ][ col ];
   }
}
document.writeln( "El valor más pequeño es: " + menor );
k) Instrucción sin repetición para mostrar los elementos de la primera fila de t.
document.writeln( t[ 0 ][ 0 ] + " " + t[ 0 ][ 1 ] + " " + t[ 0 ][ 2 ] );
l) Serie de instrucciones para imprimir el arreglo t en formato tabular ordenado con índices de fila y columna.
var salida = "<table><thead><th>Fila / Col</th><th>0</th><th>1</th><th>2</th></thead><tbody>";
for ( var fila = 0; fila < t.length; ++fila )
{
   salida += "<tr><th>" + fila + "</th>";
   for ( var col = 0; col < t[ fila ].length; ++col )
   {
      salida += "<td>" + t[ fila ][ col ] + "</td>";
   }
   salida += "</tr>";
}
salida += "</tbody></table>";
document.getElementById( "salida" ).innerHTML = salida;
