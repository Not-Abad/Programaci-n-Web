Ejercicio 10.5: Encontrar y corregir errores

Identificación de errores lógicos y de sintaxis en el manejo de índices de arreglos.

a) Desbordamiento de índice en ciclo for

ErrorSe hace referencia al elemento de un arreglo fuera de los límites del arreglo (b[ 10 ]), ya que los índices válidos van de 0 a 9. Corrección: cambie el operador <= a <.

var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i < longitud; ++i )
{
   b[ i ] = 1;
}
b) Indexado incorrecto de arreglo bidimensional

ErrorEl indexado de arreglos multidimensionales se realiza de manera incorrecta usando una coma dentro de un solo par de corchetes. Corrección: utilice corchetes separados para cada dimensión (a[ 1 ][ 1 ] = 5;).

var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1 ][ 1 ] = 5;
