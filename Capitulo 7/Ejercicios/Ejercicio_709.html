Ejercicio 7.9: Identificar y corregir errores en fragmentos de código

Corrección de cuatro errores comunes en bucles e instrucciones condicionales.

  1. a) if ( edad >= 65 );
    Error: El punto y coma después de la condición corta la instrucción if. Debe eliminarse el punto y coma.
  2. b) var x = 1, total;
    Error: La variable total no está inicializada (es undefined), por lo que total += x genera NaN. Debe inicializarse total = 0;.
  3. c) while ( x <= 100 ) total += x; ++x;
    Error: Faltan llaves en el cuerpo del while. Al no tener llaves, sólo ejecuta total += x;, creando un ciclo infinito porque ++x está fuera.
  4. d) while ( y > 0 ) { document.writeln( y ); ++y; }
    Error: Se incrementa ++y en lugar de decrementar --y. Esto hace que y siempre sea mayor que 0, produciendo un ciclo infinito.
