Ejercicio 7.19: El Problema del "Else Suelto"

Análisis de asociación entre instrucciones condicionales e instrucciones else sin delimitación de llaves.

  1. a) Para la estructura sin llaves:
    if ( x < 10 )
      if ( y > 10 )
        document.writeln( "<p>*****</p>" );
      else
        document.writeln( "<p>#####</p>" );
    document.writeln( "<p>$$$$$</p>" );

    Cuando x = 9 y y = 11: Imprime ***** y $$$$$

    Cuando x = 11 y y = 9: Imprime $$$$$ (El else está asociado al segundo if, el cual no se evalúa al fallar el primero)

  2. b) Para la estructura con llaves:
    if ( x < 10 ) {
      if ( y > 10 )
        document.writeln( "<p>*****</p>" );
    }
    else {
      document.writeln( "<p>#####</p>" );
      document.writeln( "<p>$$$$$</p>" );
    }

    Cuando x = 9 y y = 11: Imprime *****

    Cuando x = 11 y y = 9: Imprime ##### y $$$$$ (El else está asociado explícitamente al primer if)
