Ejercicio 7.6: Valor de variables después del cálculo

Determinar el valor de cada variable considerando que inicialmente todas tienen el valor entero 5.

  1. a) producto *= x++;
    producto = 25, x = 6

    Como es postincremento (x++), se usa el valor actual de x (5) para multiplicar producto (5 * 5 = 25) y luego x se incrementa a 6.

  2. b) cociente /= ++x;
    cociente = 0.833333..., x = 6

    Como es preincremento (++x), x se incrementa primero a 6, y luego se divide cociente (5 / 6 = 0.833333...).
