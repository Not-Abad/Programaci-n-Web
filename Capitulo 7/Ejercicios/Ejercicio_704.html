Ejercicio 7.4: Instrucciones de cálculo y asignación

Escribir una instrucción en JavaScript para realizar cada una de las tareas indicadas.

  1. a) Declarar las variables suma y x.
    var suma, x;
  2. b) Asignar 1 a la variable x.
    x = 1;
  3. c) Asignar 0 a la variable suma.
    suma = 0;
  4. d) Sumar la variable x a suma y asignar el resultado a la variable suma.
    suma += x;
  5. e) Imprimir "La suma es: ", seguido del valor de la variable suma.
    document.writeln( "La suma es: " + suma );
