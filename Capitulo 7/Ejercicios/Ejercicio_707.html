Ejercicio 7.7: Identificar y corregir errores

Análisis de código para detectar y solucionar errores en estructuras de control.

  1. a) Código con error:
    while ( c <= 5 ) {
        producto *= c;
        ++c;

    Error: Falta la llave derecha de cierre (}) del cuerpo de la instrucción while.
    Corrección: Agregar la llave de cierre } después de ++c;.
  2. b) Código con error:
    if ( genero == 1 )
        document.writeln( "Mujer" );
    else;
        document.writeln( "Hombre" );

    Error: El punto y coma (;) después de else produce un error lógico, haciendo que la segunda instrucción siempre se ejecutará.
    Corrección: Eliminar el punto y coma después de else.
