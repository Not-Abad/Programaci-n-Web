Ejercicio 7.2: Formas de sumar 1 a una variable

Cuatro instrucciones de JavaScript distintas para incrementar en 1 la variable x.

  1. Asignación directa:
    x = x + 1;
  2. Operador de asignación de adición:
    x += 1;
  3. Operador de preincremento:
    ++x;
  4. Operador de postincremento:
    x++;
