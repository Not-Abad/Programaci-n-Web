Ejercicio 7.8: Error en instrucción de repetición while

Análisis de la instrucción while ( z >= 0 ) suma += z;.

Instrucción analizada:
while ( z >= 0 )
    suma += z;

Error: El valor de la variable z nunca se modifica dentro del cuerpo de la instrucción while. Por lo tanto, si la condición ( z >= 0 ) es verdadera, se produce un ciclo infinito.

Solución: La variable z debe decrementarse dentro del ciclo (por ejemplo, con --z;) para que en algún momento tome un valor menor a 0 y la repetición termine.
