Ejercicio 7.3: Instrucciones en JavaScript

Escribir instrucciones en JavaScript para realizar tareas específicas.

  1. a) Asignar la suma de x y y a z, e incrementar el valor de x en 1 después del cálculo. Usar sólo una instrucción.
    z = x++ + y;
  2. b) Evaluar si el valor de la variable cuenta es mayor que 10. De ser así, imprimir "Cuenta es mayor que 10".
    if ( cuenta > 10 )
        document.writeln( "Cuenta es mayor que 10" );
  3. c) Decrementar la variable x en 1, luego restarla a la variable total. Usar sólo una instrucción.
    total -= --x;
  4. d) Calcular el residuo después de dividir q entre divisor y asignar el resultado a q (de dos maneras distintas).
    Forma 1: q %= divisor;

    Forma 2: q = q % divisor;
