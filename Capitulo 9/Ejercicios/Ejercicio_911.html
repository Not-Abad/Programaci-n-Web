Ejercicio 9.11: Asignación de enteros aleatorios en rangos

Fórmulas y prueba interactiva de asignación aleatoria a la variable n.

  1. 1 ≤ n ≤ 2: n = Math.floor(1 + Math.random() * 2);
  2. 1 ≤ n ≤ 100: n = Math.floor(1 + Math.random() * 100);
  3. 0 ≤ n ≤ 9: n = Math.floor(Math.random() * 10);
  4. 1000 ≤ n ≤ 1112: n = Math.floor(1000 + Math.random() * 113);
  5. -1 ≤ n ≤ 1: n = Math.floor(-1 + Math.random() * 3);
  6. -3 ≤ n ≤ 11: n = Math.floor(-3 + Math.random() * 15);
