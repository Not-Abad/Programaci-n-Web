Conceptos de alcance y métodos de retorno en funciones.

  1. El alcance de un identificador es la parte del programa en donde puede usarse.
  2. Las tres formas de devolver el control de una función invocada al que la llamó son return;, return expresión; o encontrar la llave derecha de cierre de una función.
  3. La función Math.random se utiliza para producir números aleatorios.
  4. Las variables declaradas en un bloque o en la lista de parámetros de una función son de alcance local.
