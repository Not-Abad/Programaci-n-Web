Ejercicio 9.5: Corrección de errores en funciones

Identificación y solución de errores comunes en la declaración de funciones.

a) Segmento con error:

method g()
{
    document.writeln( "Dentro del m&eacute;todo g" );
}

Error: method no es la palabra clave que se utiliza para comenzar la definición de una función.

Corrección: Cambiar method a function.

b) Segmento con error:

// Esta función debe devolver la suma de sus argumentos
function suma( x, y )
{
    var resultado;
    resultado = x + y;
}

Error: Se supone que la función debe devolver un valor, pero no utiliza la instrucción de retorno.

Corrección: Eliminar la variable resultado y colocar la instrucción return x + y; o agregar return resultado; al final del cuerpo de la función.

c) Segmento con error:

function f( a );
{
    document.writeln( a );
}

Error: Existe un punto y coma sintácticamente incorrecto después del paréntesis derecho de la lista de parámetros.

Corrección: Eliminar el punto y coma (;) después del paréntesis derecho de la lista de parámetros.
