Ejercicio 8.13: Valores Asignados a x en una Instrucción Switch

Rastreo de ejecución de la variable x para valores de k = 1, 2, 3, 4 y 10.

Código analizado:
switch ( k ) {
  case 1: break;
  case 2:
  case 3: ++k; break;
  case 4: --k; break;
  default: k *= 3;
}
x = k;

Resultados del rastreo:

  • Para k = 1: Se ejecuta case 1: break;. El valor de k no cambia. x = 1
  • Para k = 2: Cae en case 3:, ejecuta ++k; break;. k se vuelve 3. x = 3
  • Para k = 3: Ejecuta case 3: ++k; break;. k se vuelve 4. x = 4
  • Para k = 4: Ejecuta case 4: --k; break;. k se vuelve 3. x = 3
  • Para k = 10: Cae en default: k *= 3;. k se vuelve 30. x = 30
