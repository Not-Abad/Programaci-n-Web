Ejercicio 8.4: Errores en Segmentos de Código

Análisis de código para detectar múltiples fallos sintácticos y lógicos en ciclos y selecciones.

  1. a) For ( x = 100, x >= 1, ++x ) document.writeln( x );
    Errores: 'For' debe ser en minúsculas 'for'; los argumentos dentro del for se separan con punto y coma (;) y no con comas (,); y se debe decrementar (--x) para ir de 100 a 1.
  2. b) switch ( valor % 2 ) { case 0: document.writeln( "Entero par" ); case 1: ... }
    Error: Falta la instrucción break al final de case 0. Sin break, un número par imprimirá "Entero par" y continuará ejecutando case 1 imprimiendo "Entero impar".
  3. c) for ( x = 19; x >= 1; x += 2 ) document.writeln( x );
    Error: Se incrementa x (x += 2) cuando la condición es x >= 1 partiendo de 19, generando un ciclo infinito. Debe decrementarse (x -= 2).
  4. d) contador = 2; do { ... contador += 2; } While ( contador < 100 );
    Errores: 'While' debe ser en minúsculas 'while'; para incluir el 100, la condición debe ser ( contador <= 100 ).
