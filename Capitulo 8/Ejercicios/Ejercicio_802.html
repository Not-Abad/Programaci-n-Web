Ejercicio 8.2: Instrucciones en JavaScript

Construcción de instrucciones para realizar tareas específicas de repetición y cálculo.

  1. a) Sumar los enteros impares entre 1 y 99 mediante una instrucción for.
    suma = 0;
    for ( cuenta = 1; cuenta <= 99; cuenta += 2 )
        suma += cuenta;
  2. b) Calcular el valor de 2.5 elevado a la potencia de 3 usando el método pow.
    Math.pow( 2.5, 3 );
  3. c) Imprimir los enteros del 1 al 20 mediante ciclo while (5 enteros por línea).
    x = 1;
    document.writeln( "<p>" );
    while ( x <= 20 ) {
        document.write( x + " " );
        if ( x % 5 == 0 )
            document.write( "</p><p>" );
        ++x;
    }
  4. d) Repetir el inciso c) utilizando una instrucción for.
    document.writeln( "<p>" );
    for ( x = 1; x <= 20; x++ ) {
        document.write( x + " " );
        if ( x % 5 == 0 )
            document.write( "</p><p>" );
    }
    document.writeln( "</p>" );
