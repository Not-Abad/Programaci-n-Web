Ejercicio 8.3: Encontrar y Corregir Errores

Análisis de código de autoevaluación para identificar errores sintácticos y lógicos.

  1. a) x = 1; while ( x <= 10 ); ++x; }
    Error: El punto y coma después del encabezado while provoca un ciclo infinito; además falta una llave izquierda.
    Corrección: Reemplazar el punto y coma por una llave izquierda ({), o eliminar tanto el punto y coma (;) como la llave derecha (}).
  2. b) switch ( n ) { case 1: document.writeln( "El número es 1" ); case 2: ... }
    Error: Falta una instrucción break en las instrucciones del primer case.
    Corrección: Agregue una instrucción break al final de las instrucciones para el primer case (salvo que intencionalmente se desee la caída en cascada al case 2).
  3. c) n = 1; while ( n < 10 ) document.writeln( n++ );
    Error: Se está utilizando un operador relacional inadecuado (<) en la condición de continuación del ciclo para imprimir hasta 10.
    Corrección: Use <= en vez de <, o cambie el 10 a 11.
