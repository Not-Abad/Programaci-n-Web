Ejercicio 8.12: Evaluación de Expresiones Relacionales

Evaluación de expresiones considerando i = 1, j = 2, k = 3 y m = 2.

  1. a) document.writeln( i == 1 );
    true
  2. b) document.writeln( j == 3 );
    false
  3. c) document.writeln( i >= 1 && j < 4 );
    true
  4. d) document.writeln( m <= 99 && k < m );
    false
  5. e) document.writeln( j >= i || k == m );
    true
  6. f) document.writeln( k + m < j || 3 - j >= k );
    false
  7. g) document.writeln( !( k > m ) );
    false

¿Son necesarios los paréntesis en cada caso?

No son estrictamente necesarios porque los operadores aritméticos tienen mayor precedencia que los operadores relacionales, e igual precedencia mayor sobre los lógicos. Sin embargo, se recomiendan para mejorar la claridad y evitar errores de lectura.
